# Public AVsync project site

Buildless, self-contained HTML/CSS for GitHub Pages. `index.html` promotes the
AVsync iOS app and self-hosted MXL generator/analyzer separately. Privacy is
available in German and English; support points to the maintainer and issues.
No remote fonts, analytics or JavaScript are needed.

Preview from this folder with `python3 -m http.server 8099 --bind 127.0.0.1`.
Publish the contents of `site/` to the repository's `gh-pages` branch root.
Keep `.nojekyll`; Pages source must be `gh-pages` with path `/`. Publication
must not merge or release unrelated application changes. Before updating the
policy, inspect actual capture, temporary-file, state, diagnostics and network
code. Do not promise automatic deletion where none exists.

- https://leeo86.github.io/mxl-avsync/privacy.html
